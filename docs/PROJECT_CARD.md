# Карточка проекта 203

| Поле | Значение |
|---|---|
| Номер | 203 |
| Название | Конструктор первого рабочего дня |
| Репозиторий | `first-day-builder` |
| Профиль | браузерное приложение, статический сайт |
| Аудитория | наставник или руководитель, который встречает нового сотрудника, и сам новичок |

## Задача

Собрать понятный план первого дня: когда и где встречи, что сделать самостоятельно, что почитать, к кому обращаться. Не допустить накладок по времени и битых ссылок. Передать новичку отдельную страницу, которая открывается без доступа к редактору.

## Сценарий

1. Наставник выбирает дату, пишет приветствие, добавляет контакты.
2. Добавляет встречи, задачи и материалы, задаёт время и длительность, место, описание, ссылку и людей.
3. Приложение подсвечивает пересечения и неверные ссылки, на шкале дня конфликтующие блоки красные. Замечания ведут к нужному полю.
4. Когда замечаний нет, появляется предпросмотр, и наставник скачивает страницу `first-day-<дата>.html`.
5. Новичок открывает файл в любом браузере: расписание по времени, отдельный раздел материалов и задач без времени, контакты.

## Функции версии 1.0

- Поля плана: заголовок, дата, имя новичка, наставник, приветствие.
- Контакты (имя, роль, почта, телефон) и их назначение блокам.
- Блоки трёх типов, порядок стрелками, сдвиг на 15 минут, «Без времени» для задач с сохранением прежнего времени.
- Проверка интервалов (в пределах суток, длительность от 1 минуты) и пересечений с учётом всех предыдущих блоков, смежные блоки допустимы.
- Ссылки только http/https, адрес без схемы дополняется `https://`.
- Шкала дня с дорожками для пересечений.
- Предпросмотр в изолированном iframe и та же страница в файле, без скриптов, с CSP.
- Автосохранение в IndexedDB с защитой от перезаписи из другой вкладки, файл черновика JSON, «Вернуть» для удаления и замены.
- Нижняя панель статуса на узком экране.

## Практический результат

Новичок получает один файл с планом, который можно открыть на телефоне или распечатать. Наставник уверен, что встречи не накладываются, а ссылки ведут на сайты, а не на `javascript:`.

## Границы текущей версии

- Один день. Многодневные программы адаптации, повторяющиеся события и часовые пояса не поддерживаются.
- Нет отправки по почте и интеграции с календарём: страница передаётся файлом.
- Перетаскивания блоков по шкале нет: время меняется полем и кнопками сдвига, порядок — стрелками.
- Черновик хранится только в этом браузере, совместного редактирования нет.
