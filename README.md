# 203 · Конструктор первого рабочего дня

`first-day-builder` — браузерное приложение без сервера. Наставник выбирает дату и собирает план дня из встреч, самостоятельных задач и материалов: меняет порядок, назначает контакты, добавляет ссылки. Приложение находит пересечения по времени и неверные ссылки, показывает предпросмотр и выгружает отдельную HTML-страницу, которую новичок открывает без доступа к редактору и без интернета.

## Быстрый старт: готовая сборка

Готовая статическая сборка лежит в папке `dist/` (входит в ZIP-выпуск, в git не коммитится). Открывайте её через локальный HTTP-сервер: при открытии `index.html` двойным щелчком браузер блокирует модульные скрипты.

```bash
# вариант 1 — Node.js 22.12+ (без установки зависимостей)
node scripts/serve-static.mjs --dir dist --port 4203 --base /
# открыть http://127.0.0.1:4203/

# вариант 2 — Python 3
python3 -m http.server 4203 --directory dist
# открыть http://localhost:4203/
```

Сборка использует относительные пути и работает и из корня сайта, и из вложенного пути вроде `https://<user>.github.io/first-day-builder/`.

## Демонстрационный сценарий

1. Нажмите **«Загрузить демоплан»**: понедельник, 23 ноября 2026, новичок Мария, 10 блоков, 3 контакта.
2. Подсвечены три блока: длинная «Настройка ноутбука и доступов» 10:00–12:00 и две вложенные в неё встречи («Знакомство с командой» 10:30, «Получить пропуск» 11:15). «Обед с командой» в 12:00 смежный и не подсвечен. Панель проверки: «Перед выгрузкой исправьте: 2 замечания».
3. Перенесите «Настройку ноутбука» на 13:00. Появится «Время и ссылки в порядке: 7 по времени, 3 без времени» и предпросмотр.
4. Нажмите **«Скачать страницу для новичка»**: файл `first-day-2026-11-23.html`. Откройте его отдельно: расписание по времени, материалы без времени отдельным разделом, контакты. Подпись «Возьмите <b>паспорт</b>…» показана текстом.
5. Обновите страницу редактора (F5): черновик восстановится из IndexedDB. «Сохранить черновик в файл» и «Открыть черновик» переносят план JSON-файлом.

## Разработка

Требования: Node.js 22.12 или новее, npm 10+.

```bash
npm ci                      # зависимости строго по package-lock.json
npm run dev                 # http://localhost:5203/ с горячей перезагрузкой
```

## Проверки и сборка

```bash
npm run typecheck           # TypeScript
npm test                    # Vitest: время, пересечения, ссылки, экспорт HTML, файл плана
npm run build               # сборка в dist/
npm run e2e:install         # один раз: тестовый браузер Chromium для Playwright
npm run e2e                 # Playwright по dist/: вложенный путь /first-day-builder/ и корень
npm run verify              # всё подряд: typecheck → test → build → e2e
```

Сквозные тесты сами поднимают статический сервер на портах 4203 и 4213 и проверяют именно содержимое `dist/`. Проверить развёрнутую копию: `E2E_BASE_URL=https://<адрес>/ npx playwright test --project=nested-path`.

## Где что лежит

| Путь | Назначение |
|---|---|
| `src/core/timeline-validation.ts` | проверка полей, интервалов и пересечений `validatePlan(plan)` |
| `src/core/html-export.ts` | `renderPlanHtml(plan)` — автономная страница, экранирование, CSP |
| `src/core/links.ts` | нормализация ссылок: только http и https |
| `src/core/plan-store.ts` | IndexedDB с ревизиями, файл плана JSON, резервная копия |
| `src/core/model.ts`, `src/core/time.ts` | `DayPlan`, демоплан, минуты ↔ ЧЧ:ММ, дата словами |
| `src/ui/` | `PlanEditor` (модуль plan-editor), `Timeline`, `usePersistentDraft`, `Field` |
| `e2e/` | сквозные сценарии Playwright |
| `dist/` | готовая сборка (в ZIP) |
| `docs/` | карточка продукта, архитектура, приёмка, ассеты, исходное ТЗ |

## Данные

Черновик хранится только в этом браузере: IndexedDB `first-day-builder`. Файлы: страница новичка `first-day-<дата>.html` и черновик `first-day-<дата>.plan.json` (формат `first-day-builder`, версия 1). Сервер и учётные записи не нужны. Выгруженная страница не содержит скриптов и не обращается к сети.
