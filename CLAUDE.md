# Правила работы с проектом 203 Конструктор первого рабочего дня

Браузерное приложение React + TypeScript + Vite без сервера. Черновик живёт в IndexedDB, результат — автономная HTML-страница.

## Где что находится

- Интерфейс и публичные маршруты — `index.html`, `src/main.tsx`, `src/App.tsx`, `src/ui/PlanEditor.tsx`, `src/ui/Timeline.tsx`, `src/ui/Field.tsx`, `src/ui/usePersistentDraft.ts`, `src/styles.css`. Маршрутов нет, одна страница.
- Предметная логика и хранение — `src/core/timeline-validation.ts`, `src/core/html-export.ts`, `src/core/links.ts`, `src/core/plan-store.ts`, `src/core/model.ts`, `src/core/time.ts`.
- Данные, ассеты и демоматериалы — демоплан `demoPlan()` в `src/core/model.ts` (вымышленные люди, адреса `@example.com`), иконка `public/favicon.svg` (собственная), готовая сборка `dist/`.
- Тесты и документация — `src/core/*.test.ts` (Vitest), `e2e/*.spec.ts` (Playwright), `docs/`.

## Команды и сценарий

- Установка — `npm ci`, для e2e один раз `npm run e2e:install`.
- Запуск и адрес — `npm run dev` → http://localhost:5203/; готовая сборка `npm run serve:dist` → http://127.0.0.1:4203/.
- Проверки и сборка — `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e` (по `dist/`, порты 4203 и 4213), всё вместе `npm run verify`.
- Данные и результат показательного сценария — «Загрузить демоплан» → подсвечены «Настройка ноутбука и доступов» 10:00–12:00 и две вложенные встречи, 2 замечания → перенос «Настройки» на 13:00 → «Время и ссылки в порядке: 7 по времени, 3 без времени» → «Скачать страницу для новичка» → `first-day-2026-11-23.html` открывается отдельно.

## Инварианты проекта

- Время блока — минуты от начала выбранной даты, `start + duration ≤ 1440`. Встреча всегда со временем, задача может быть без времени, материал всегда без времени.
- Пересечения ищутся проходом по отсортированным блокам с набором незакончившихся (учитывает самую позднюю границу всех предыдущих, а не только соседа). Смежные блоки (конец = начало) допустимы. Результат сверяется с полным перебором в юнит-тесте.
- Предпросмотр и файл строятся одной функцией `renderPlanHtml(plan)` из одного `DayPlan`. Предпросмотр — `iframe srcdoc` без `allow-scripts`.
- Весь пользовательский текст в экспорте проходит `escapeHtml`. Ссылки — только нормализованные http/https из `normalizeLink`, подпись ссылки — из ввода наставника. В странице CSP `default-src 'none'`, скриптов нет.
- Выгрузка возможна только без замечаний (`validatePlan(plan).ok`).
- Запись в IndexedDB только через `putIfRev`. Пока черновик читается, редактор недоступен.
- Снятие блока со шкалы («Без времени», смена типа на материал) запоминает время в `parkedStart` и возвращает его.
- Имена файлов только латиницей и цифрами.
- Сборка с `base: './'`: должна работать из корня и из вложенного пути. Проверяют это e2e-проекты `nested-path` и `root-path`.
